# 🚢 Misi Archimedes

Media pembelajaran interaktif **Hukum Archimedes** untuk siswa SMP Kelas 9 / Fase D.

Website ini membawa siswa melalui alur **5E Learning Cycle** (Engage, Explore, Explain, Elaborate, Evaluate) dengan simulasi fisika, eksperimen virtual, dan tantangan nyata.

## ✨ Fitur Utama

- 🔎 **Engage** — Fenomena misteri kapal baja
- 🧪 **Explore** — Laboratorium virtual Archimedes
- 💡 **Concept** — Membangun konsep dari data
- 🌊 **Simulation** — Density comparator
- 🚢 **Challenge** — Desain kapal dengan 3 skenario
- 📝 **Evaluate** — 30 soal bervariasi (PG, PG kompleks, menjodohkan, isian, HOTS)
- 🏆 **Certificate** — Sertifikat penyelesaian A4 portrait

## 🛠️ Teknologi

- Vite + React + TypeScript
- Canvas API untuk simulasi fisika
- LocalStorage untuk menyimpan progress
- Tanpa backend — semua berjalan di browser siswa
